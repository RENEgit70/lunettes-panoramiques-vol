# Lunettes Panoramiques Vol

Prototype d'une application mobile simulant des lunettes panoramiques pour passagers d'avion : vue à 360° (mer de nuages, sol vu d'en haut, soleil couchant) qui suit les mouvements de tête grâce au gyroscope du téléphone.

## Fonctionnalités
- Vue panoramique 360° avec suivi de tête (gyroscope)
- 3 caméras simulées : panoramique, ventrale, queue
- Mode écran partagé pour casque/lunettes en carton
- Chargement d'une vidéo 360° personnelle
- Repli tactile si aucun capteur détecté

## Lancer le prototype
Ouvrir `index.html` dans le navigateur d'un téléphone mobile.

Projet créé avec l'aide de Muse dans le cadre d'un apprentissage de l'IA et de la création d'applications.
